# Katalog Testów (tests)

W tym katalogu znajdują się projekty testowe dla aplikacji **AI-ISO-Creator**:

- **AI-ISO-Creator.Tests**: Testy jednostkowe oraz integracyjne weryfikujące:
  - Poprawność serializacji i deserializacji receptur ISO z formatu generowanego przez Gemini AI.
  - Generowanie poleceń budowania kontenerowego.
  - Walidację danych wejściowych i zarządzanie stanem zadań budowania.
