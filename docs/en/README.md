# AI-ISO-Creator Technical Documentation

AI-ISO-Creator customizes existing Linux Live ISO images. The user supplies the source image, chooses the desktop environment, and reviews the proposed package changes. Gemini can suggest packages to add or remove and provide example commands, but it does not select the distribution or desktop, and its command suggestions are never executed.
