# Katalog Źródłowy (src)

Ten katalog zawiera kod źródłowy aplikacji **AI-ISO-Creator**, zorganizowany w architekturze modułowej:

- **AI-ISO-Creator.Core**: Rdzeń logiki biznesowej, komunikacja z modelem Gemini AI, orkiestrator budowania ISO oraz modele danych.
- **AI-ISO-Creator.Api**: Serwer aplikacji (ASP.NET Core Minimal API) obsługujący komunikację z frontendem i streaming logów procesu budowy.
- **AI-ISO-Creator.Frontend**: Interfejs graficzny użytkownika (HTML, CSS, JavaScript) zapewniający wygodną i lekką obsługę w trybie desktopowym.
